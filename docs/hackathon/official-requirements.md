# CHIA Hackathon — official requirements snapshot

Checked: 2026-09-18.

Primary source: https://agentic-arch.org/hackathon.html

## Final deadline

- Final submissions: **Sep 24, 2026 (AoE)**.
- Short-term funded accounts: usable **Sep 21 through Sep 23 at 11:59 PM PT**.

## Final submission components

1. **4-page paper** describing the loop and findings.
   - two-column ACM/IEEE style;
   - PDF;
   - AI assistance in writing is allowed but must be acknowledged at the end;
   - human authors remain responsible for contents, tone, and quality.
2. **Open-sourced CHIA loop + produced results**.
   - GitHub is strongly preferred;
   - artifact/release URL must be supplied with the submission.
3. Submission system: https://a3-chia-hackathon-26.hotcrp.com/

## Project implication

The final artifact cannot remain only in a private repository. Before submission, publish this repository or make a clean public release containing the runnable loop, configurations, reproducibility instructions, and non-sensitive results.
