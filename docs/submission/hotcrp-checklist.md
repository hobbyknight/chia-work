# HotCRP + final release checklist

Submission site: https://a3-chia-hackathon-26.hotcrp.com/

## Register early

- [ ] Title entered.
- [ ] Preliminary author list entered.
- [ ] Basic abstract entered.
- [ ] Confirm these remain editable until the final deadline.

## Paper

- [ ] Maximum 4 pages as required by the hackathon instructions.
- [ ] Two-column ACM/IEEE style.
- [ ] Problem/motivation clear.
- [ ] CHIA loop architecture shown.
- [ ] Experimental methodology reproducible.
- [ ] U0–S4 definitions stable.
- [ ] Main results grounded in real logs only.
- [ ] Limitations stated.
- [ ] AI-assistance acknowledgment included at end.
- [ ] PDF visually checked.

## Artifact

- [ ] Repository/release is public.
- [ ] README has one-command or minimal-step reproduction path.
- [ ] No secrets in current tree/history/release.
- [ ] Environment/upstream revisions recorded.
- [ ] Loop implementation included.
- [ ] Configs/prompts included where licensing/privacy permits.
- [ ] Raw or sufficient result data included.
- [ ] Analysis script included.
- [ ] Artifact URL tested in logged-out/incognito context.

## Final

- [ ] Upload final PDF.
- [ ] Provide public artifact URL.
- [ ] Re-check author/title/abstract/highlights.
- [ ] Submit before Sep 24 AoE; do not plan to use the final minutes as normal working time.
